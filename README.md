# 🎬 Movie Search App

A responsive Movie Search Application built using:

- HTML
- Tailwind CSS
- Vanilla JavaScript
- OMDb API

---

# ✨ Features

- Search movies by title
- Display movie posters
- View movie ratings
- Responsive movie cards
- Movie details modal popup
- API integration using OMDb API

---

# 🛠 Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (ES6)
- OMDb API

---

# 📚 Skills Practiced

- Fetch API
- Async/Await
- DOM Manipulation
- Event Handling
- Responsive Design
- Dynamic Cards Layout
- Modal Implementation

---
